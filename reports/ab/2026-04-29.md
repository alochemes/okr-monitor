# A/B Report — 2026-04-29 (last 14 days)

**A/B reporting is not configured yet.** To enable:

1. Create a PostHog account (or use existing).
2. In PostHog → Project settings → API keys, create a **Personal API key** with `query:read` scope.
3. Add to local `.env`:
   ```
   POSTHOG_API_KEY=phx_...        # personal API key
   POSTHOG_PROJECT_ID=12345       # numeric project id
   POSTHOG_HOST=https://us.i.posthog.com   # or eu.i.posthog.com
   ```
4. Add `NEXT_PUBLIC_POSTHOG_KEY=phc_...` (the project key, not personal) to `web/.env.local` so the landing page actually emits events.
5. In PostHog → Feature flags, create:
   - `hero_headline` with variants `control` / `variant_a` / `variant_b`, equal split.
   - `hero_cta` with variants `control` / `variant_a` / `variant_b`, equal split.
6. Re-run this script. First report shows up after ~100 exposures per variant.
